Positioning in CSS

Sticky Position:

Element acts like relative until a scroll position is reached, then sticks like fixed.

Static Positon:

Static position in CSS is the default positioning where an element stays in the normal document flow and ignores top, left, right, and bottom.

Relative Positon:

Element stays in normal flow but can be moved using top, left, right, bottom relative to its original position.

Absolute Positon:

Element is removed from normal flow and positioned relative to the nearest positioned ancestor (not static).

Fixed Postion:

Element is removed from normal flow and positioned relative to the viewport (screen), stays fixed on scroll.
